# GLM-5.3-Flash decode on Xeon Gold and Tesla V100, 2026-10-03

The target is 40 decode tokens/s. The best qualified result so far is
28.91 tokens/s for a 512-token response; the target has not been reached.

Original upstream `main` at `99f3dbd` was merged into `glm53f` as `3bbb469`
before optimization. Experiments used an isolated merged source tree and an SM70 release build.

Two V100-PCIE 32 GB GPUs, 35 CPU workers, 131072-token allocated context,
32768 MiB per GPU, and the full 4096-token coding prompt are used for timing.
Each case has three 128-token requests and three 512-token requests. Decode
rates count the actual `output_tokens - 1` state advances, excluding startup
and the warm-up request. Prompt processing and cache preparation are outside
the decode interval.

| Configuration | 128-token decode, median tok/s | 512-token decode, median tok/s |
|---|---:|---:|
| Baseline | 26.696 | 27.397 |
| Device experts, device reduction, layer graphs | 26.547 | 27.392 |
| Above plus asynchronous MoE | 27.348 | 28.266 |
| Above plus fused clamped activation and reused q8 inputs | 27.797 | 28.763 |
| Above plus original singleton IQ kernels, admission threshold 3 | 27.915 | **28.912** |
| Admission threshold 1 | 26.176 | 27.969 |
| Admission threshold 2 | 26.960 | 28.133 |
| Admission threshold 6 | 27.222 | 28.436 |
| Admission threshold 12 | 27.156 | 28.169 |
| Threshold 6, cache window 64 | 27.214 | 28.258 |
| Threshold 6, cache window 1024 | 26.795 | 28.425 |

All completed cases finished with identical repeated token IDs. Their generated
C++ compiled with `-Wall -Wextra -Werror` and passed 400532 oracle cases.
The first combined candidate also passed an eight-step full-logit and rollback
comparison against direct execution. Binary SHA256:
`7ab641fbd831bbe9ce5430a674f66d3a9a066dea1cc0bdd3f13fd0b5311589a9`.

Asynchronous MoE returns GPU 1 results on its own stream and waits on an event
before reduction. Expert replacement waits for the selected victim layer's
readers. Pinned reduction inputs have separate storage per layer. Fused
clamped activation matches the original GPU output bits on real expert
blocks. Quantization reuse avoids packing the same mixer, router, and shared
expert inputs again.

The full-model sanitizer run completed repeated 64-token requests with zero
errors and identical output. Instrumentation uses 24576 MiB budgets and a
1024-launch synchronization limit to leave room for tracking memory. The
performance runs retain their full 32768 MiB budgets. The benchmark rejects
internal sanitizer failures even when a zero-error summary is present.

A decode-only Nsight trace reports approximately 25.33 ms of GPU 0 kernels
and 5.28 ms of GPU 1 kernels per token, with roughly 96 MB of adaptive host
uploads per token. These are instrumented diagnostics, not throughput results.

Fused RMS normalization was rejected: component float/q8 bits, guards, CPU
oracle, and memcheck passed, but full-logit parity failed on the first graph
replay. The decoder integration and kernel changes were removed. Experimental
sources remain in the ignored continuation directory for diagnosis.

The latest candidate passed the same eight-step full-logit and rollback check,
real-model expert bit checks, and repeated 64-token full-model sanitizer requests.
Binary SHA256:
`b856bde1e8e04bed60bafd4f8f3045eccb686e16f5ee5fe565732b0854534bba`.
Its best 512-token result is 5.5% faster than the merged baseline and produces
exactly the same token IDs. Larger admission thresholds are slower; those
configurations produce different deterministic answers, each passing the
C++ oracle. They are comparison runs rather than the selected recipe.
The minimum observation threshold is configurable with `STRATA_GLM_ADMIT_MIN`
(1–64, default 3); no weights or context are changed.

The best recipe enables `STRATA_OLD_IQ_MMVQ=1`, `STRATA_GLM_ASYNC_MOE=1`,
`STRATA_GLM_FUSED_CLAMP=1`, and `STRATA_GLM_QUANT_ONCE=1` alongside the resident
expert graph configuration. See [V100 recipe](../tools/glm_v100.env)
for all settings. Admission thresholds 1 and 2 are also slower. The default
threshold 3 and cache window 256 remain selected.

The remaining gap is substantial: 40 tokens/s requires a 25 ms decode step,
versus approximately 34.6 ms for the current best. The trace attributes about
8.8 ms/token of GPU 0 work to q5/q6 matrix-vector kernels; CPU expert misses
also remain on the critical path. Cache tuning alone has not closed this gap.
A next structural experiment should target these costs or batched resident
expert verification for speculative decode, with full-logit, rollback, and
repeated-output gates. Earlier MTP trials were rejected for nondeterminism.
